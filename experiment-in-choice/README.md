# Code recovered from "experiment in choice"

These folders hold the code from `experiment_in_choice.txt`, a transcript of an
earlier undirected-generation session. In that session the user mostly replied
"➡️" and the model picked each next step. The code is grouped into the 13 project
cycles the transcript itself marks.

This commit is a **verbatim extraction**: every file is copied exactly from the
transcript, with only the blank lines at either end trimmed. `manifest.json`
maps each file to its source line range. Any repairs are in later commits, so
`git diff` against this commit shows every change made to the original.
