# Open-Experiment
Experiment in prompt-minimal open-ended generation.

- [`experiment-in-choice/`](experiment-in-choice/): the code from an earlier
  undirected session's transcript, extracted, repaired and tested. It's 13
  projects, one per cycle of that session.
- [`autogram/`](autogram/): a search for sentences that correctly count their
  own letters, the first thing made in this session.
